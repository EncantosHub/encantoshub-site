O que é um hiperlink?

Um hiperlink (ou simplesmente “link”) é um elemento clicável que leva o usuário de uma página para outra — dentro do mesmo site ou para um site externo. Na linguagem HTML, ele é representado pela tag <a>, chamada de âncora.

Exemplo básico de link HTML:

<a href="https://www.seuexemplo.com">Visite nosso site</a>

Como fazer um link HTML: estrutura básica

Elemento Função
<a> Define o link (âncora)
href URL de destino do link
target Define onde abrir (mesma aba, nova aba etc.)
title Mostra uma dica ao passar o mouse
rel Informa ao Google a relação entre páginas (SEO)

Tipos de hiperlink com exemplos práticos

1. Link com texto âncora (ideal para SEO)

<a href="https://www.seusite.com">Acesse nossa página inicial</a>

Use palavras-chave no texto âncora sempre que possível.

2. Link que abre na mesma aba

<a href="https://www.seusite.com" target="_self">Clique aqui</a>

3. Link que abre em nova aba (ótimo para externos)

<a href="https://www.seusite.com" target="_blank">Abrir em nova guia</a>

Mantém o usuário no seu site e é indicado para links externos.

4. Link com legenda (title)

<a href="https://www.seusite.com" title="Ir para o site principal">Visite o site</a>

5. Link em imagem

<a href="https://www.seusite.com">
  <img src="logo.png" alt="Logo da empresa" />
</a>

6. Link em botão (com JavaScript)

<button onclick="window.location.href='https://www.seusite.com'">Visitar</button>

7. Link para e-mail

<a href="mailto:contato@seusite.com">Enviar e-mail</a>

8. Link para telefone

<a href="tel:+559999999999">Ligar agora</a>

Link absoluto vs link relativo

Tipo Exemplo Quando usar
Absoluto https://www.seusite.com/contato Para links externos ou completos
Relativo /contato Para links internos no mesmo domínio

Atributo rel e SEO

O atributo rel ajuda o Google a entender a natureza do link. Principais valores:

  • rel="nofollow" → Não transfere autoridade (ex: links pagos)
  • rel="sponsored" → Indica publicidade
  • rel="ugc" → Conteúdo gerado por usuários (ex: comentários)
  • rel="follow" → Implícito, transfere autoridade

Exemplo ideal para SEO:

<a href="https://parceiro.com" rel="nofollow" title="Conheça nosso parceiro" target="_blank">Visite o parceiro</a>

Boas práticas de links para SEO

  • Use texto âncora claro e descritivo (ex: "saiba mais sobre nossos serviços" em vez de "clique aqui").
  • Priorize links internos estratégicos para distribuir autoridade.
  • Abra links externos em nova aba e use rel="nofollow" quando necessário.
  • Evite links apenas em botões com JavaScript.
  • Mantenha URLs limpas e legíveis (ex: /servicos/consultoria-seo).
